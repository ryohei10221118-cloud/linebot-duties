## 功能說明

這個智慧鬧鐘系統會：
- ✅ 自動判斷明天是否上班
- ✅ 上班日才響鈴
- ✅ 休假日完全靜音
- ✅ 不同班別用不同鬧鐘時間
- ✅ 支援多個鬧鐘（重複提醒）
- ✅ 完全自動化，一次設定終身受用

**工作原理：**
```
班表系統 → Google 日曆 → iOS 捷徑 → 自動開關鬧鐘
```

## 設定步驟

### 第一步：部署 Google Apps Script 程式碼

1. **上傳新檔案**
   - 打開你的 Google Apps Script 專案
   - 在左側檔案列表，點擊「+」→「指令碼」
   - 檔案名稱輸入：`CalendarSync`
   - 將 `CalendarSync.gs` 的內容貼上

2. **測試日曆同步功能**
   - 在函數下拉選單選擇 `testCalendarSync`
   - 修改程式碼第 234 行的測試用戶名稱（改成你的名字）：
     ```javascript
     const testUserName = 'Ricky';  // 👈 改成你的名字
     ```
   - 點擊「執行」
   - **第一次會要求授權** - 點擊「審查權限」→ 選擇你的 Google 帳號 → 進階 → 前往專案 → 允許
   - 查看執行日誌，確認「✅ 同步完成！」

3. **確認日曆已建立**
   - 開啟 Google 日曆：https://calendar.google.com
   - 在左側「其他日曆」找到「班表通知」
   - 確認有你未來的班表事件
   - 不同班別會用不同顏色：
     - 🔴 早班：淺紅色
     - 🔵 中班：淺藍色
     - 🟣 夜班：紫色
     - 休假日：不會出現事件

4. **設定每日自動同步**
   - 在函數下拉選單選擇 `setupDailyCalendarSync`
   - 點擊「執行」
   - 系統會建立每天凌晨 2:00 的自動觸發器
   - 之後每天都會自動同步班表到日曆

5. **部署更新（重要！）**
   - 點擊右上角「部署」→「管理部署」
   - 在現有部署旁點擊「✏️」（編輯）
   - 版本選擇「新版本」
   - 點擊「部署」
   - 完成！

### 第二步：在 iPhone 建立鬧鐘

在開始設定捷徑之前，先建立好鬧鐘：

#### 早班鬧鐘（3個）
1. 打開「時鐘」App → 「鬧鐘」
2. 建立鬧鐘 **5:30** - 標籤改成「早班-1」
3. 建立鬧鐘 **5:40** - 標籤改成「早班-2」
4. 建立鬧鐘 **5:50** - 標籤改成「早班-3」
5. **全部關閉**（不勾選）

#### 中班鬧鐘（2個）
1. 建立鬧鐘 **7:00** - 標籤改成「中班-1」
2. 建立鬧鐘 **7:15** - 標籤改成「中班-2」
3. **全部關閉**（不勾選）

#### 夜班鬧鐘（2個）
1. 建立鬧鐘 **14:00** - 標籤改成「夜班-1」
2. 建立鬧鐘 **14:10** - 標籤改成「夜班-2」
3. **全部關閉**（不勾選）

> **重要：** 鬧鐘標籤必須包含「早班」、「中班」或「夜班」這些關鍵字，捷徑才能識別！

### 第三步：設定 iOS 捷徑

#### 方法 A：匯入現成捷徑（推薦）

1. 用 iPhone Safari 打開這個連結：
   ```
   https://www.icloud.com/shortcuts/[捷徑ID]
   ```
   ⚠️ 連結稍後提供，需要我先上傳捷徑檔案

2. 點擊「加入捷徑」
3. 完成！跳到「第四步」測試

#### 方法 B：手動建立捷徑（詳細步驟）

如果匯入連結無法使用，請按照以下步驟手動建立：

##### 1. 建立新捷徑

1. 打開「捷徑」App
2. 點擊右上角「+」
3. 點擊「加入動作」

##### 2. 加入「尋找行事曆事件」動作

1. 搜尋「尋找行事曆事件」→ 點擊加入
2. 設定篩選條件：
   - 日曆 = 「班表通知」
   - 開始日期 = 「明天」
   - 結束日期 = 「明天」

##### 3. 加入「如果」判斷

1. 搜尋「如果」→ 點擊加入
2. 設定條件：
   - 如果 **「行事曆事件」** **「有任何值」**

##### 4. 在「如果」區塊內加入動作

在「如果」和「否則」之間：

**步驟 4.1：取得事件標題**
1. 搜尋「取得名稱」→ 點擊加入
2. 從「行事曆事件」取得「名稱」

**步驟 4.2：判斷早班**
1. 搜尋「如果」→ 點擊加入
2. 設定條件：
   - 如果 **「名稱」** **「包含」** **「早班」**

**步驟 4.3：開啟早班鬧鐘**
在這個「如果」區塊內：
1. 搜尋「切換鬧鐘」→ 點擊加入
2. 設定：**開啟** 所有標籤為 **「早班」** 的鬧鐘
3. （系統會自動找到所有包含「早班」的鬧鐘）

**步驟 4.4：關閉其他鬧鐘**
繼續在早班區塊內：
1. 搜尋「切換鬧鐘」→ 點擊加入
2. 設定：**關閉** 所有標籤為 **「中班」** 的鬧鐘
3. 搜尋「切換鬧鐘」→ 點擊加入
4. 設定：**關閉** 所有標籤為 **「夜班」** 的鬧鐘

**步驟 4.5：重複中班和夜班的判斷**
在早班「如果」區塊的「否則」裡：
1. 加入新的「如果」判斷中班（重複步驟 4.2-4.4）
2. 在中班「否則」裡，加入「如果」判斷夜班

##### 5. 在主要「否則」區塊內（沒有班表事件）

加入「關閉所有鬧鐘」：
1. 搜尋「切換鬧鐘」→ 點擊加入
2. 設定：**關閉** 所有標籤為 **「早班」** 的鬧鐘
3. 重複 2 次，分別關閉「中班」和「夜班」鬧鐘

##### 6. 加入通知（可選）

在最後加入：
1. 搜尋「顯示通知」→ 點擊加入
2. 設定通知文字：「明天鬧鐘已設定完成」

##### 7. 儲存捷徑

1. 點擊右上角「下一步」
2. 命名：「智慧鬧鐘控制」
3. 點擊「完成」

---

### 第四步：設定自動化

讓捷徑每天晚上自動執行：

1. 在「捷徑」App，切換到「自動化」分頁
2. 點擊右上角「+」
3. 選擇「建立個人自動化操作」
4. 選擇「特定時間」
5. 設定時間：**21:00**（晚上 9 點）
6. 重複：**每天**
7. 點擊「下一步」
8. 搜尋「執行捷徑」→ 點擊加入
9. 點擊「捷徑」，選擇「智慧鬧鐘控制」
10. 點擊「下一步」
11. **關閉「執行前先詢問」** ⚠️ 這很重要！
12. 點擊「完成」

**完成！** 之後每天晚上 9 點，系統會自動：
1. 檢查明天的 Google 日曆
2. 如果有班 → 開啟對應班別的鬧鐘
3. 如果休假 → 關閉所有鬧鐘

## 多鬧鐘設定

### 為什麼需要多個鬧鐘？
- 第一個鬧鐘：準時起床
- 第二個鬧鐘：再睡 10 分鐘
- 第三個鬧鐘：最後警告

### 設定範例

**早班（需要早起）：**
```
5:30 - 早班-1（輕柔音樂）
5:40 - 早班-2（中等音量）
5:50 - 早班-3（大聲警報）
```

**中班（正常時間）：**
```
7:00 - 中班-1
7:15 - 中班-2
```

**夜班（下午起床）：**
```
14:00 - 夜班-1
14:10 - 夜班-2
```

### 自訂鬧鐘間隔

你可以自由調整鬧鐘時間和數量，只要：
1. 標籤包含對應的班別關鍵字（早班/中班/夜班）
2. 在捷徑中設定正確的標籤篩選

## 常見問題

### Q1: 為什麼鬧鐘沒有自動開啟？

**檢查清單：**
1. ✅ Google 日曆是否有明天的班表事件？
   - 打開 Google 日曆 → 檢查「班表通知」
2. ✅ 自動化是否關閉「執行前先詢問」？
   - 捷徑 App → 自動化 → 檢查設定
3. ✅ 鬧鐘標籤是否正確？
   - 時鐘 App → 檢查每個鬧鐘的標籤
4. ✅ 日曆同步是否正常？
   - 用 LINE 發送「同步日曆」手動更新

### Q2: 休假日鬧鐘還是響了？

**可能原因：**
- 日曆中有事件（可能是其他事件）
- 捷徑判斷條件設定錯誤
- 鬧鐘是手動開啟的（不是由捷徑控制）

**解決方法：**
1. 檢查 Google 日曆，確認休假日沒有「班表通知」事件
2. 手動執行捷徑測試
3. 檢查捷徑的「否則」區塊是否正確關閉所有鬧鐘

### Q3: 可以臨時調整嗎？

可以！有兩種方式：

**方式 1：臨時關閉自動化**
- 捷徑 App → 自動化 → 關閉「智慧鬧鐘控制」
- 手動設定鬧鐘
- 隔天再開啟自動化

**方式 2：手動執行捷徑**
- 打開捷徑 App
- 點擊「智慧鬧鐘控制」
- 立即執行一次

### Q4: 我想改鬧鐘時間怎麼辦？

1. 打開「時鐘」App
2. 修改對應鬧鐘的時間
3. **保持標籤不變**（早班/中班/夜班）
4. 完成！捷徑會自動識別新時間

### Q5: 可以加入更多鬧鐘嗎？

可以！只要：
1. 在時鐘 App 建立新鬧鐘
2. 標籤設定為對應班別（例如「早班-4」）
3. 捷徑會自動找到並控制所有相同標籤的鬧鐘

### Q6: 如何手動同步日曆？

兩種方式：

**方式 1：用 LINE Bot**
- 發送訊息：「同步日曆」
- 系統會立即同步未來 30 天班表

**方式 2：執行 Google Apps Script**
- 打開 Apps Script 專案
- 選擇函數 `syncUserScheduleToCalendar`
- 點擊「執行」
