# iOS 智慧鬧鐘設定指南

上班日才響、休假日不響的 iPhone 鬧鐘。

```
班表（Google Sheets）
   ↓ 每天凌晨 2:00 自動同步
Google 日曆「班表通知」
   ↓ 每天 20:30 iOS 捷徑讀取「明天」的事件
iPhone 鬧鐘：先全部關閉，再只開明天那個班別的鬧鐘
   ↓ 捷徑最後回報給 LINE Bot
LINE 通知：「⏰ 明天早班，已經開啟鬧鐘，早點休息~」
   （約 20:45～21:15 沒收到回報 → LINE 警告）
```

> 本指南的畫面文字以 iOS 27（繁體中文）為準。其他版本的選單名稱可能略有不同。

---

## 一、Google Apps Script 設定

### 1. 加入 `CalendarSync.gs`

1. 打開 Apps Script 專案，點左側「檔案」旁的「＋」→ **指令碼**（不要選 HTML）
2. 檔名輸入 `CalendarSync`
3. 貼上 repo 裡 `google-apps-script/CalendarSync.gs` 的完整內容，存檔

### 2. 測試同步

1. 把 `testCalendarSync` 裡的名字改成你在班表 B 欄的名字（大小寫要一樣）：
   ```javascript
   const testUserName = 'Sunny';
   ```
2. 函數選單選 `testCalendarSync` → 執行
3. 第一次會要求授權：審查權限 → 選帳號 → 進階 → 前往專案 → 允許
4. 打開 Google 日曆，確認「班表通知」裡有「`名字 - 早班 M1`」這類事件
   - 休假（O、P、病假等）不會建立事件

### 3. 設定每日自動同步

函數選單選 `setupDailyCalendarSync` → 執行一次。

- 會建立每天凌晨 2:00 執行 `syncAllUsersScheduleToCalendar` 的觸發器
- 只同步「用戶配置」裡**有綁定、而且是完整模式**的人，不會把所有同事都塞進日曆
- 可在左側「觸發條件」（時鐘圖示）確認

### 4. 部署新版本（LINE「同步日曆」指令需要）

部署 → 管理部署 → 編輯 → 版本選「新版本」→ 部署。

## 二、iPhone 準備

### 1. 讓 iPhone 看得到「班表通知」日曆

設定 → 行事曆 → 帳號 → 你的 Google 帳號 → 開啟「行事曆」。
打開行事曆 App，確認看得到「班表通知」的事件。

### 2. 建立鬧鐘

在時鐘 App 建立鬧鐘，每個都設定：

- **重複：每天**
- **標籤：早班／中班／夜班**（只寫這兩個字）
- **先關閉**

例如：

| 時間 | 標籤 |
|------|------|
| 5:30、5:40、5:50 | 早班 |
| 7:00、7:15 | 中班 |
| 14:00、14:10 | 夜班 |

同一個班別的鬧鐘標籤都一樣沒關係，捷徑會用標籤把整組找出來。

> 標籤必須是「夜班」，不是「晚班」。日曆事件寫的是「夜班」，捷徑裡的字要跟鬧鐘標籤一致。

## 三、建立捷徑

完成後的結構：

```
1. 尋找以下 全部 為真的 行事曆行程
     開始日期 在未來 1 天
     行事曆 是 班表通知
     標題 包含 Sunny

2. 尋找以下 任一 為真的 鬧鐘
     標籤 是 早班
     標籤 是 中班
     標籤 是 夜班

3. 重複 鬧鐘 中的每個項目
     關閉 重複項目
   結束重複

4. 如果 行事曆行程 包含 早班
     尋找 鬧鐘，其中 標籤 是 早班
     重複 鬧鐘 中的每個項目
       開啟 重複項目
     結束重複
   結束如果

5. 同第 4 段，早班 → 中班
6. 同第 4 段，早班 → 夜班

7. 取得 URL 內容（回報給 LINE Bot，見第五節）
```

也就是：每晚先把所有班別的鬧鐘關掉，再只開明天那個班的。休假日沒有事件，三個「如果」都不成立，所以全部維持關閉。

### 步驟 1：尋找行事曆行程

1. 搜尋「尋找行事曆行程」加入
2. 最上方選 **全部**
3. 開始日期：**在未來 1 天**
4. 加入過濾條件：**行事曆 是 班表通知**
5. 加入過濾條件：**標題 包含 你的名字**

> 不要留下沒選值的條件（例如「行事曆 是 選擇」）。「全部」模式下空的條件永遠不成立，會一個事件都找不到。

### 步驟 2～3：先關閉所有班別鬧鐘

1. 搜尋「尋找鬧鐘」加入，最上方選 **任一**，加三條：標籤 是 早班／中班／夜班
2. 搜尋「重複」，選 **重複每一個**，中間那格選 **鬧鐘**（步驟 2 的結果）
3. 搜尋「切換鬧鐘」加入，操作選 **關閉**，鬧鐘欄選變數 **重複項目**
4. 確認「關閉」在「重複」和「結束重複」**中間**。新加的動作跑到外面的話，長按「結束重複」往下拖

> 「切換鬧鐘」的鬧鐘欄不能空著，空著的話執行時會跳出來問你要切換哪一個，自動化就會卡住。

### 步驟 4：早班

1. 搜尋「如果」加入
2. 條件第一格選 **行事曆行程**（日曆「23」圖示那個，名稱可能顯示成「包含」）
3. 再點一次那個變數 → **類型** 改成 **文字**
4. 條件改成 **包含**，輸入 **早班**
5. 在「如果」裡面加入：
   - 「尋找鬧鐘」：標籤 是 早班
   - 「重複每一個」
   - 「切換鬧鐘」：**開啟**，鬧鐘欄選 **重複項目**

最快的做法是把步驟 2～3 整段複製進「如果」裡，再把條件改成只留早班、「關閉」改成「開啟」。

### 步驟 5～6：中班、夜班

把步驟 4 整段（「如果」到「結束如果」）複製兩份，把「如果」條件和「尋找鬧鐘」的標籤都改成中班、夜班。

### 關閉通知

每個「切換鬧鐘」動作點右邊的「›」展開，把 **執行時顯示** 關掉，執行時就不會跳通知。

## 四、設定自動化

1. 捷徑 App →「自動化」→ 右上「＋」→ **特定時間**
2. 時間 **20:30**（下午），**每天**
3. 選 **立即執行**，關掉 **執行時通知**
4. 下一步選剛剛做好的捷徑

## 五、LINE 回報

捷徑跑完後把明天的日曆事件傳給 LINE Bot，Bot 會推播給你：

- `⏰ 明天早班，已經開啟鬧鐘，早點休息~`
- `😴 明天沒有班` / `鬧鐘已全部關閉`

捷徑中途出錯會直接停止，走不到回報這一步。所以 Bot 每晚約 20:45～21:15 會檢查：今晚沒收到你的回報，就傳 `⚠️ 今晚鬧鐘捷徑沒有回報`。沒執行、出錯、手機沒網路都會收到這個警告。這個檢查只對回報過至少一次的人生效。

訊息只推播給「用戶配置」裡綁定該名字的 LINE 帳號，其他訂閱官方帳號的人收不到。

### 1. Apps Script

1. **程式碼.gs** 最上面的設定區（`RAPIDAPI_HOST` 下面）加一行密碼，自己取一串英數字，不要有空格或中文：
   ```javascript
   const ALARM_REPORT_TOKEN = '你自己取的密碼';
   ```
   只能寫一次，不要兩個檔案都寫。
2. **程式碼.gs** 的 `doPost` 裡，`const json = JSON.parse(e.postData.contents);` 下面加：
   ```javascript
   if (json.type === 'alarm_report') {
     return handleAlarmReport(json);
   }
   ```
3. **CalendarSync.gs** 最下面貼上 `// ==================== 鬧鐘捷徑回報 ====================` 開始到檔案結尾的整段
4. 存檔，執行一次 `setupAlarmReportCheck`，設定每晚的檢查
5. **部署新版本**：部署 → 管理部署 → 編輯 → 版本選「新版本」→ 部署（網址不變）。沒部署的話 doPost 的修改不會生效

### 2. 捷徑

在最後一個「結束如果」**下面**加入 **取得 URL 內容**：

- **URL**：Web App 網址，跟 LINE Webhook 填的是同一個，結尾是 `/exec`
- **方式**：POST
- **要求本文**：JSON，4 個欄位都選「文字」：

| 鍵 | 值 |
|---|---|
| `type` | `alarm_report` |
| `token` | 程式碼.gs 裡設的密碼 |
| `name` | 你的名字（例如 `Sunny`） |
| `event` | 變數 📅 行事曆行程（畫面上可能顯示成「包含」），再點它把**類型改成「文字」** |

> 截圖分享時記得遮住密碼和網址。

## 六、測試

1. 打開行事曆 App，看明天「班表通知」的事件是什麼班
2. 把時鐘 App 裡所有班別的鬧鐘都打開
3. 回捷徑 App 按 ▶ 執行
4. 檢查時鐘 App：只有明天那個班的鬧鐘是開的；明天沒事件的話全部關閉
5. LINE 應該馬上收到回報訊息

## 常見問題

### 鬧鐘全部被關掉，明天的班卻沒開

- **明天沒有事件**：先看行事曆 App。LINE 傳「明天上班嗎」有班、日曆卻沒有，就是還沒同步，傳「同步日曆」或執行 `testCalendarSync`
- **步驟 1 有空的過濾條件**：刪掉沒選值的那條
- **「關閉」那段在「如果」下面**：它要排在三個「如果」前面，否則會把剛開的鬧鐘又關掉

### 「如果」只有「包含任何數值」，沒有地方輸入文字

變數還是「行事曆行程」類型。點它 → 類型改 **文字**。

### 「如果」前面是時鐘圖示的「標籤」

選到鬧鐘的標籤了。點它改選日曆圖示的 **行事曆行程**。

### 「如果」裡的尋找鬧鐘變成「過濾 📅… 其中 標籤 是 早班」

它接到日曆事件了。點「📅…」→ **清除變數**，就會變回「尋找 鬧鐘」。

### 早班那天，中班、夜班的鬧鐘也被打開

「如果」裡的「重複」接到了步驟 2 的全部鬧鐘。點中間那格 → 清除變數 → **選取變數** → 點它正上方那個「尋找鬧鐘」。

### 捷徑跑完了，LINE 沒收到回報

到 Apps Script 左側「執行作業」看最新一筆 doPost 的日誌：

- **密碼錯誤**：捷徑的 `token` 和程式碼.gs 的 `ALARM_REPORT_TOKEN` 不一樣
- **找不到已綁定的完整模式用戶**：`name` 要跟「用戶配置」裡的名字一模一樣
- **沒有新的執行紀錄**：改完程式碼後還沒部署新版本，或捷徑的 URL 貼錯

### 明天有班，LINE 卻說「明天沒有班」

`event` 欄位的變數沒有把類型改成「文字」。

### 臨時換班

日曆每天凌晨 2:00 才會更新。當天換班的話，在 LINE 傳 **同步日曆**，晚上 8:30 捷徑執行時才會用到新的班表。

### 會同步到同事的班嗎？

每日自動同步只同步「用戶配置」裡有綁定、而且是完整模式的人。日曆裡如果有以前測試留下的別人的事件，捷徑也會因為「標題 包含 你的名字」而略過，可以在 Google 日曆手動刪掉。
